用 Rust 从零搭一个生产级通用 AI 助手。

> 本系列教程将分为十一个章节（0-10），每章包含建什么、引入哪些文件与依赖、怎么验收。
> 每个模块设计为可插拔可替换的组件，讲明白为什么存在、解决上一阶段的什么问题，并提供系统级的抽象与实现。

## 前置

* Rust（所有权、async/await、trait、模块、通道通信）；具备一定的底层系统开发基础
* 一个 OpenAI 兼容 API key（`OPENAI_BASE_URL` 可指向兼容供应商）

## 章节目录

十一个章节各占一个目录，内含该章的子模块（`ch0X.md`）。

| 章节 | 内容模块 | 核心解决的问题与架构演进 |
| --- | --- | --- |
| 0. 导览与环境 | 脚手架、跑通「Hello, Agent」 | **建立基建**：异步运行时（Tokio）基础与 API 客户端封装。 |
| 1. 最小可用 Agent 与结构化 | Loop、Tools 路由、**JSON Schema 约束** | **奠定确定性基石**：确保模型输出能被 Rust 强类型系统（Serde）安全反序列化，避免后续状态机崩溃。 |
| 2. 工具链与安全沙箱 | Permission、Hooks 拦截器、Todo 队列 | **引入执行边界**：实现工具调用的干预与审计，构建中间件体系。 |
| 3. 上下文与长程记忆 | Context 组装、Compact、**向量与 KV 抽象** | **解决上下文溢出**：抽象底层存储 Trait，接入轻量级 KV（如 SlateDB）与纯内存的近似最近邻（ANN/HNSW）检索机制。 |
| 4. 持久化与异步状态机 | Task Graph、后台异步执行、Cron | **生命周期管理**：处理 `Send + Sync` 边界，管理跨会话状态与定时挂起/唤醒。 |
| 5. 评测与确定性测试 | **Record/Replay 盒带**、任务集评测框架（LLM-as-judge）、轨迹指标与回归对比 | **建立守门机制**：把非确定性的 Agent 行为纳入确定性测试；为后续所有章节提供回归防线。 |
| 6. 单体编排与收束 | Integrated Harness、Workflow (DAG)、Goal | **复杂任务解构**：基于有向无环图实现任务依赖规划，确保单体 Agent 能收敛到最终目标，避免死循环。 |
| 7. 插件化与标准化生态 | **Skills 抽象层**、**MCP Client 集成** | **突破 Rust 编译边界**：将能力从进程内剥离，通过标准协议动态挂载外部生态（Python 脚本、本地文件系统）。 |
| 8. 多 Agent 协作与网络 | Subagent 路由、Teams 网络、Actor 消息通信 | **状态隔离与并发**：拆分上下文域；采用 Actor 模型与无锁通道（Channel）实现独立 Agent 的心跳维持与联邦协作。 |
| 9. 生产化基建 | 可观测性 (Tracing)、韧性 (熔断)、元数据注册 | **解决系统黑盒与高可用**：分布式追踪落盘；引入基于 etcd 的 Leader 选举与节点发现机制以支持远程 Agent。 |
| 10. 进阶拓展 | 多模态输入、**极致性能调优 (SIMD/Tokenizer)** | **压榨硬件性能**：本地轻量级计算的指令级优化（如针对 128 维向量距离计算的 f32x8 SIMD 优化）与 Tokenizer 效率。 |

## 章节产出物与版本约定

* 每章结束都有一版**能跑的 bytemaker**；核心机制章每章一个 git 阶段标签（`s01` 到 `s19`），学生可逐章 `git checkout s0X` 对照最小实现。生产化与进阶章在 `s19` 之上增量提交，另起 `prod01`..`prod05` 标签。
* 每章配套：本章 diff（相对上一章）、单元测试、一条可复现的验收 prompt。
* 自第 6 章起，每章验收追加一条铁律：**新增 eval 任务集条目 + 离线回放全绿**——新能力必须先有失败模式测试，再有实现。
* 模块详解（作用/设计初衷/数据流/结构速查/不变量）随章落到 `docs/modules/<module>.md`，与本大纲交叉引用。

## 阅读路径

* **想知道「为什么有这章」** → `docs/README.md` 的失败模式表 + `docs/modules/<module>.md` 的「设计初衷/演进」。
* **想知道「这章建什么、怎么验收」** → 本文件的章节目录，链接到各子模块文档。
* **想知道「模块内部长什么样」** → `docs/modules/<module>.md` 的「结构速查」+ 源码 `//!` 文档。
